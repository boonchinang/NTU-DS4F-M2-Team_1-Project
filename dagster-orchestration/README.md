# Dagster Pipeline Orchestration & Schedule

This directory manages the end-to-end Dagster orchestration DAG and daily scheduling.

## 🚀 How to Launch Dagster Orchestration

1. Navigate to `dagster-orchestration/`:
   ```bash
   cd dagster-orchestration
   ```

2. Launch the Dagster Webserver UI:
   ```bash
   dagster dev
   ```

3. Open your browser at `http://localhost:3000` to view the asset lineage graph or click **"Launch Run"** for manual ad-hoc execution.
